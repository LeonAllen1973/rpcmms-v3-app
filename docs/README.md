# RPCMMS Documentation

This directory contains high-level documentation for **RPCMMS v3**.

The purpose of this documentation is to clearly explain:
- The system architecture
- The maintenance philosophy behind RPCMMS
- The asset model and core concepts
- Design decisions relevant to industrial and oil & gas operations

This documentation is written to be understandable by:
- Engineers and developers
- Maintenance professionals
- Technical stakeholders and investors

---

## Documentation Structure

- **Architecture Overview**
  - High-level system architecture
  - SaaS-first design
  - Optional on-premise deployment model

- **Maintenance Philosophy**
  - Why RPCMMS is asset-centric
  - Alignment with real maintenance workflows
  - Focus on usability and data quality

- **Asset Model**
  - Asset hierarchy definition
  - Relationship between assets, components, and parts
  - Impact on work orders, PMs, and inventory

- **Core Modules**
  - Work Requests & Work Orders
  - Planned Maintenance
  - Inventory & Spare Parts
  - Safety & Compliance

- **Roadmap & Scope**
  - What is included in RPCMMS v3
  - What is intentionally excluded
  - Future expansion areas
